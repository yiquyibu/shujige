# 枢机阁文章本地混合检索

## 使用

双击 `启动检索.cmd`。首次启动会对 `../修复版网页/` 中同名的 298 对 HTML／MD 文档建立索引；之后会复用索引。构建完成后浏览器打开 `http://127.0.0.1:8767/`。关闭命令窗口即停止服务。

默认显示 50 条结果，可在页面中自行修改数量。可切换混合、关键词和语义检索。

可选命令行：

```powershell
& 'D:\app\Python\python.exe' '.\hybrid_search.py' search '关公像有什么区别？' --mode hybrid --limit 10
```

## 数据与方法

- 只读取 MD 文字。内嵌图片的 Base64 数据在 Markdown 解析前剔除；原始 HTML／MD 不会被修改。
- 关键词检索使用中文二字、三字片段及英文词构成的 SQLite FTS5 倒排索引。
- 语义检索使用本机已有的 `D:\AI_project\LM\Tips_For_MiniLM\bge-small-zh-v1.5`，在 CPU 上生成 512 维向量。模型只读使用，无需联网。
- 混合模式将两路候选按排名合并；结果保留文章名、片段序号、原文片段和打开原文的入口。
- 对“哪些是假的”“是否虚构”等有明确真假判断要求的问题，追加文章级判断词和片段级证据排序；结果数量不超过 400 时，候选范围保持一致。判断词只用于定位原文，不能证明文章中的判断正确。
- 检索结果只显示“精选留言”之前的文章正文片段，避免读者评论挤占前排；全文页仍可查看原文中保留的留言。
- `index/` 保存 `chunks.sqlite3`、`vectors.npy` 和 `manifest.json`。源 MD 的大小或修改时间变化后，下次启动会重建索引。
- 本工具提供检索和原文定位。界面不生成模型总结；结果中的说法以所示原文为准。

构建脚本：`hybrid_search.py build`。输入版本、切块参数、依赖版本、文档数和向量维度记录在 `index/manifest.json`。

本次构建实际得到 298 篇文章、1,610,600 个文本字符、4,994 个片段、512 维向量；索引文件合计约 40 MB。已用“关公像有什么区别？”、“2019-06-25”和“遇到运势低迷该怎么办”检查三种检索方式，并在进程内检查首页、检索接口和全文页均正常返回。

## 环境

Windows PowerShell 7、`D:\app\Python\python.exe`，以及已有的 `numpy`、`sentence-transformers`、`torch`、`beautifulsoup4`、`markdown-it-py`、`fastapi`、`uvicorn`。本工具不安装依赖，也不发送文章内容到外部服务。
